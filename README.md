# tech-dock

Курсовая работа по теме «Турагентство» (информационная система) и Python-скрипт, который автоматически собирает её в оформленный документ Word по ГОСТ 7.32-2017.

**Автор:** Улюшев Захар Евгеньевич, группа 024ИСП, 3 курс, Новосибирский политехнический колледж.

## Что в репозитории

| Файл / папка | Назначение |
|---|---|
| `Ulyushev_ZE_Kursovaya_turagentstvo.docx` | Готовая курсовая работа |
| `build_kursovaya.py` | Скрипт сборки документа (python-docx) |
| `assets/` | Рисунки и схемы, которые вставляются в документ |
| `SLA.txt` | Краткие выдержки из публичных SLA информационных систем (например, Amazon Compute SLA) |

## Что умеет скрипт

- задаёт шрифты и интервалы по ГОСТ (Times New Roman 14, код Courier New);
- собирает титульный лист, содержание, заголовки разделов и подразделов;
- оформляет таблицы с границами и заливкой, подписи к рисункам и таблицам;
- вставляет рисунки из `assets/` и фрагменты кода;
- добавляет нумерацию страниц и обновляемые поля.

## Запуск

Нужен Python 3 и библиотека python-docx.

```bash
pip install python-docx
python build_kursovaya.py
```

Результат появится в корне проекта: `Ulyushev_ZE_Kursovaya_turagentstvo.docx`.
